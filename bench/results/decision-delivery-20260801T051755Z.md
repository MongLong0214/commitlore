## 9. Active-record delivery before the first edit

These numbers measure what each route hands a fresh agent before its first edit. Delivery is a ceiling on recovery: an agent cannot recover a record it was never given, and being given one is no evidence it was read. The method is registered in `bench/DECISION-DELIVERY.md`.

Method: build an answer key from `git log HEAD` with Git's own trailer parser and a second implementation of the SPEC §5 lifecycle fold (`bench/deterministic/census.ts`, which imports nothing from the product). Fold at **2026-08-01T05:17:45.000Z**, HEAD's committer instant, which is also the instant the projections evaluate at. Then, for every evaluation path, hand each route its text and count the record ids in it. A record is recovered when its id appears; there is no partial credit.

Corpus: **327 records** over 518 commits (179 merges, 328 carrying a record) — **320 active, 7 superseded, 0 expired**. 1220 paths are tracked at HEAD and 160 of them are declared generated by the repository's own `.gitattributes`.

Answer-key checks: the block walk resolved 9 `Supersedes:` trailer(s) against 9 found by a raw line scan of the same messages, and 0 `Expires:` against 0. 6 record(s) sit on commits that changed no path — a merge changes none — so no path-scoped route can reach them.

**Population: authored paths (`.gitattributes` generated paths excluded).** 1037 of 1060 candidate paths carry at least one active record; the other 23 have a `0/0` recall and are not scored. The primary denominator is **2149** (path, active record) pairs, of which 164 are reachable only through a rename. The repository-wide denominator is 320 active records per path.

Path recall is the primary figure and its denominator is the active records attached to the path being edited. Repo-wide recall uses every active record in the repository as the denominator for every path; it is reported so the denominator choice is auditable, not because it is the right question to ask of a path-scoped route.

The stale column is the error term the issue asks for: a record the repository has retired and a route surfaced anyway.
