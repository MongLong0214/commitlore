Make injected EvidenceReader implementations fully supported by application execution. Before any operational port is invoked, verify that every evidence name required by each selected category pack is advertised by ports.evidence.evidence_names. If a selected pack cannot be supported, fail with a ValueError that identifies the pack and its unavailable requirement(s).

When repository files cannot be read, or when the configured evidence reader cannot read evidence, record absent category evidence using the configured reader's vocabulary. Those absence records must have empty values and an absent basis, and category results must remain absent rather than being treated as ordinary non-matches. This must work for a custom reader whose vocabulary includes a non-default evidence name.
