# ADR-0006: 소비는 push — 훅·MCP 주입, 결정론적 프로젝션, 등급 라우팅

- Status: Accepted (2026-07-26)

## Context

pull 전용 소비(에이전트가 스스로 조회)는 실사용에서 잊힌다(D8). 또한 무큐레이션·무스코프 메모리 주입은 실증에서 성능을 해쳤다(CTIM-Rover) — 주입은 좁고, 등급화되고, 예산 상한이 있어야 한다.

## Decision

1. **주입 훅**: 에이전트가 파일을 읽거나 수정하는 시점(PreToolUse 계열)에 그 경로의 활성 기록 요약을 자동 주입. 전역 덤프 금지 — 경로 스코프만.
2. **결정론적 프로젝션**: 주입 요약은 기록 스트림의 결정론적 폴드로 계산·캐시(LLM 무관, 토큰 원가 0, 재현 가능). 예산 초과 시에만 LLM 압축 옵트인.
3. **등급 라우팅**: ADR-0005 등급에 따라 지시/주장/보류 차등 전달. 스테일 원자는 주입하지 않는다.
4. **`annals guard`**: 에이전트 제안이 해당 경로의 `Ruled-out:` 원자와 매치되면 실행 전 결정론적 경고(재제안 차단 게이트).
5. **자동 수확**: 커밋 직전 transcript에서 trailer 초안 생성 → **분리된 검증자**가 근거 인용을 기계 검증, 실패 원자는 폐기(fail-explicit). 유계 수리 루프(최대 N회) 후 명시적 실패.

## Ruled-out

- CLAUDE.md류 정적 전역 컨텍스트 주입 | AGENTS.md 실증 연구군에서 조건부 역효과 확인 — 동적·경로 스코프가 구조적 우위
- 주입 요약을 매번 LLM 생성 | 비용 0 원칙 위반 + 비재현성
- 수확 에이전트 자기 검증 | maker–checker 분리 원칙 — 만든 자가 자기 숙제를 채점하지 않는다

## Consequences

- 주입 예산(기본 상한 토큰 수)은 스펙에 명시하고 AnnalsBench 노이즈 어블레이션으로 캘리브레이션(F7).
- 수확·검증의 LLM 사용은 사용자의 기존 에이전트 세션 안에서만 — 별도 과금 경로 없음.
